# Менторское ревью

Исходная версия: 14 уроков из course.py, examples/, методика и проверки приложения. Цель: переход manual QA к самостоятельным Python-автотестам с осмысленной помощью ИИ.

Сильные стороны: понятное объяснение assert, границы, return/print, конкретные исключения, подсказки и сохранение прогресса. Уроки 09 и 14 уже проверяли чувствительность тестов к внесённым дефектам.

| Проблема | Свидетельство | Исправление |
|---|---|---|
| Маршрут только вводный | 14 коротких упражнений; финал вызывает одну функцию | 20 лабораторных и проект |
| Пробелы Python | Нет отдельных работ по модулям, классам, файлам, мутации | 16-18 |
| Подмена практики инструментов | 08 проверяет список Git-команд, 13 словарь plan | Реальный конфликт, PR, браузер: 27-30 |
| pytest описан, но почти не применяется | 11 проверяет new_cart без pytest | Параметризация, yield, conftest, mocks: 20-22 |
| Только GET-каталог | Нет создания и удаления данных | Отдельный HTTP-стенд с CRUD и владельцами |
| Неполный контракт | 10 проверяет только products[0] | Все элементы и дефект второго: 24 |
| Нет диагностики и переноса | Задание с подсказкой даёт ту же галочку | Отчёт с доказательствами, повторение через неделю |
| Нет практики ИИ | Не проверяется ревью генерации | 32-33, контрольные дефекты |
| CI проверяет приложение курса | Нет самостоятельного pipeline ученика | Лабораторная 31 и запускаемые примеры |

Короткий урок сам по себе не дефект. Проблема возникает, когда одна подсказка и зелёный assert заменяют самостоятельную работу с данными, средой и непредвиденными ошибками. Вводные объяснения сохранены как разминка. Лабораторные добавляют объяснение, пример, самостоятельную задачу, критерии и перенос.

01-14 дают минимальную лексику. 15-34 выполняются последовательно в отдельном portfolio. Время в карточке включает практику, но остаётся оценкой; добавь повторение и ревью. При 8-10 часах в неделю ориентируйся на несколько месяцев, а не скорость чтения.

Маршрут рассчитан на базовую самостоятельную работу с Python/pytest/requests/Playwright. Готовность оценивается по ASSESSMENT.md. Универсальную готовность к любому стеку курс не обещает.
