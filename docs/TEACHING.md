# Методика уроков

Урок учит одному наблюдаемому навыку. Пользователь должен понимать каждую новую конструкцию, а не только копировать рабочий фрагмент.

1. **Цель:** что ученик сможет сделать после урока.
2. **Знакомая задача QA:** зачем навык нужен в работе.
3. **Объяснение:** входные данные, операция, результат; новые слова сразу определены.
4. **Пример:** короткий код без необъяснённых вспомогательных функций.
5. **Разбор:** значение каждой важной строки и символов.
6. **Ассоциация:** одна короткая аналогия, после которой возвращаемся к точному смыслу.
7. **Практика:** явный контракт входа и выхода, граничные случаи.
8. **Обратная связь:** какая проверка не прошла, а не только «неправильно».
9. **Подсказки:** сначала направление, затем конкретный приём.

Не вводить две новые абстракции без необходимости. Не использовать «просто», «очевидно» и «это легко» для объяснения. Отличать учебную имитацию от настоящего инструмента. Не засчитывать прохождение текста как практический навык.

Для проверки качества теста использовать исправную реализацию и контролируемые дефекты. Эти проверки помогают учиться, но не предназначены для защиты экзамена от намеренного обхода.

Критерии самостоятельного результата: ученик объясняет код; меняет входные данные; разбирает падение; повторяет решение без подсказок; переносит приём на похожий кейс.
