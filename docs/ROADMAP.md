# Развитие курса

## v0.1 — реализовано

14 уроков: assert, типы и функции, условия, словари, циклы, исключения, JSON, основы Git, первый pytest-тест, API-контракт, независимость данных, SQL, введение в UI, финальный тест с контролируемыми дефектами.

Редактор, SQLite, подсказки, автосохранение, история, резервная копия, обмен файлами с IDE, каталог API и корзина UI. Примеры для настоящего pytest/API/Playwright и CI проекта.

## Следующий учебный блок

- Полноценные задания на параметризацию pytest, markers, conftest и cleanup.
- Реальный Git-практикум: ветка → коммит → PR → конфликт.
- HTTP POST, авторизация, подготовка и очистка данных через API.
- Дополнительные UI-задачи, стабильность локаторов, трассировки и диагностика.
- Конфигурация через переменные окружения, небольшой Page Object.
- SQL JOIN на связке заказов и пользователей.
- Собственный GitHub Actions ученика: красный запуск → анализ лога → исправление.
- Развёрнутый финальный проект из 10–15 кейсов.

## Продуктовые улучшения

- Отдельное подтверждение повторного самостоятельного выполнения.
- План повторения по ошибкам и отложенные задания.
- Миграции содержания при обновлении курса.
- Несколько локальных профилей.

Этот список не считается уже готовыми возможностями. Завершение v0.1 — начало практики AQA, а не гарантия готовности к любой вакансии.
